O bloquinho dentro do YouTube

Esta página imita o player e o chat do YouTube. O bloquinho no canto é o mesmo script que você instala no Tampermonkey: ele liga a legenda sozinho, lê o texto dela e o chat direto da página e anota a palavra-chave. Clique em Tela antes do fim para vê-lo ler o slide, ou em Voz para reconhecer a fala sem legenda (baixa 32 MB).

Para usar no YouTube

Três passos

  1. Instale a extensão Tampermonkey (Chrome, Edge, Firefox ou Opera).
  2. Instale o script do Taquígrafo e confirme na tela que abrir.
  3. Abra a live no YouTube. O bloquinho aparece no canto; pode arrastar para onde quiser.
Instalar o script

No Chrome, se o script não rodar: Extensões → Tampermonkey → Detalhes → “Permitir scripts do usuário”.

Sem instalar pelo link

Não quer extensão? Cole o link da live e o Taquígrafo acompanha numa página dele, com a transcrição inteira na fita.
